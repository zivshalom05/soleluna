# מגדל האופק — אתר נדל״ן עם סיור תלת מימדי בגלילה

אתר סטטי ונפרד (לא קשור לחנות sole&luna). כל גלילה מזיזה את המצלמה עוד פנימה:

| שלב | מה רואים | מה מקבלים |
|---|---|---|
| 0 | הבניין מבחוץ | שם הפרויקט, קומות, דירות, אכלוס |
| 1 | מתקרבים לכניסה | מאפייני הבניין + תוויות על המודל |
| 2 | דלתות הזכוכית נפתחות ← הלובי | רשימת שירותים לדיירים |
| 3 | המעלית נפתחת, הבזק לבן | מונה קומות 1 ← 9 |
| 4 | הסלון | מפרט הדירה (שטח, מרפסת, חניות…) |
| 5 | המטבח | רשימת גימורים + מפרט טכני |
| 6 | חדר ההורים | תוכנית דירה + חדרים |
| 7 | המרפסת והנוף | טבלת מחירים ״החל מ־״ |

אחרי הסיור יש **מערכת בחירת דירה** (מפת הבניין, סינון לפי חדרים, כרטיס דירה), **טופס קביעת פגישה**, ועמוד **ניהול פניות** (`leads.html`) עם ספירת מלאי וייצוא ל־CSV.

## מובייל

- בטלפון הכרטיס יושב בתחתית המסך כמו גיליון, והסצנה מוצגת בחלק העליון (המצלמה מוזזת למעלה עם `setViewOffset`).
- מידע נוסף בכל שלב נפתח בלחיצה על ״עוד פרטים״. במחשב הוא פתוח תמיד.
- בטלפון מוצגות רק התוויות החשובות (`m: 1` במערך `LABELS`), וכמות העצים והבניינים ברקע מצטמצמת.
- כל הגופים הסטטיים מאוחדים לרשת אחת לכל חומר, כך שכל הסצנה מצוירת בכ־120 קריאות ציור.
- להצגת נתוני ביצועים: להוסיף `?debug` לכתובת ולבדוק את `window.__tour.renderer.info` בקונסול.

## הרצה מקומית

הקבצים משתמשים ב־ES modules, לכן צריך שרת (פתיחה ישירה של הקובץ לא תעבוד):

```bash
cd realestate-3d
python3 -m http.server 8000
# ואז לפתוח http://localhost:8000
```

אפשר להעלות את התיקייה כמו שהיא לכל אחסון סטטי (Netlify, Vercel, GitHub Pages, Render Static Site).

## קבצים

- `index.html` — מבנה העמוד והתוכן של כל שלב
- `scene.js` — הסצנה התלת מימדית (Three.js): הבניין, הלובי, הדירה, העיר, תחנות המצלמה והתוויות
- `ui.js` — חשיפת הכרטיסים, מונה הקומות, מפת הדירות והטופס
- `data.js` — מלאי הדירות (דמו) ושמירת פניות
- `leads.html` — ניהול פניות
- `style.css` — עיצוב

## התאמה לפרויקט אמיתי

- **תוכן ונתונים** — הטקסטים ב־`index.html`, הדירות והמחירים ב־`data.js` (`MODELS`, `PRICE_PER_M2`, וחישוב הסטטוס). טבלת המחירים במרפסת נבנית אוטומטית מהנתונים.
- **מסלול המצלמה** — מערך `STATIONS` ב־`scene.js`. כל תחנה היא מיקום ונקודת מבט, ו־`s` הוא מספר השלב. כדי להוסיף שלב: מוסיפים `<section class="stage">` ב־HTML ותחנה מתאימה.
- **תוויות על המודל** — מערך `LABELS` ב־`scene.js`.
- **מודלים אמיתיים** — אם יש קובצי GLB מהאדריכל/הדמיות, אפשר לטעון אותם עם `GLTFLoader` במקום הגופים הפשוטים, ולהשאיר את מערכת התחנות כמו שהיא.
- **הטופס** — כרגע הפניות נשמרות רק בדפדפן של המבקר (`localStorage`), ולכן `leads.html` מציג רק פניות שנשלחו מאותו דפדפן. לפני עלייה לאוויר צריך להחליף את `saveLead()` ב־`ui.js` בקריאת `fetch()` לשרת, ל־CRM או לשירות טפסים.

כל הנתונים, המחירים וההדמיות באתר הם לדוגמה בלבד.
