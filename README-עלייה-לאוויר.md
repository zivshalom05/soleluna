# sole&luna — עלייה לאוויר 🚀

האתר **מוכן לחלוטין**: קטלוג 20 פריטים, סל + קופונים, הרשמה/התחברות, checkout (דמו + Grow), ממשק אדמין, דפים משפטיים, SEO מלא, וסרטון קמפיין שמתנגן גם באייפון.

## פריסה ל-Render (5 דקות, בחינם)

1. היכנסו ל-[render.com](https://render.com) והתחברו עם GitHub.
2. **New → Blueprint** → בחרו את הריפו `zivshalom05/soleluna`.
   Render קורא את `render.yaml` ומקים את השירות לבד.
3. כשתתבקשו, מלאו את המשתנים:
   | משתנה | ערך |
   |---|---|
   | `ADMIN_PASS` | סיסמה חזקה לממשק האדמין (חובה) |
   | `GROW_USER_ID` / `GROW_PAGE_CODE` / `GROW_API_KEY` | מהדשבורד של Grow — או השאירו ריק בינתיים (יעבוד בדמו) |
4. **Apply** — תוך ~2 דקות האתר חי בכתובת `https://soleluna.onrender.com` (או דומה).

## השארת האתר ער 24/7 בחינם ("שומרי הראש")

בתוכנית Free, Render מרדים את השרת אחרי 15 דק' בלי גולשים. כדי למנוע את זה בלי לשלם,
מוסיפים "מעורר" חיצוני שפוגע באתר כל כמה דקות — בדיוק כמו ה-cron של Watchtower, רק
תדיר יותר:

1. בחשבון [cron-job.org](https://cron-job.org) שכבר פתחתם ל-Watchtower — צרו **Job נוסף** (בנפרד מזה ששולח את דו״ח ה-12 שעות):
   - **URL**: `https://<כתובת-האתר-שלכם>/api/config`
   - **Schedule**: כל 10 דקות (`*/10 * * * *`) — חייב להיות פחות מ-15 דק', אחרת השרת כבר נרדם עד שהקריאה מגיעה.
2. שמרו והפעילו את ה-Job.

**מגבלות שכדאי לדעת (זו לא תחליף מלא לתוכנית בתשלום):**
- הפינג הזה שומר את השרת ער, אבל **לא** פותר את איפוס בסיס הנתונים בכל deploy — ההזמנות עדיין נמחקות בכל עדכון קוד. מייל ההזמנות (Resend) הוא הגיבוי החשוב כאן.
- אחרי כל deploy חדש השרת עולה מחדש ממילא (קר להרף שנייה) — הפינג לא מונע את זה, רק מונע שינה בין ביקורים רגילים.
- זה workaround נפוץ ולא רשמי של Render, לא הבטחת uptime — אם תרצו משהו אמין ל-100%, השדרוג ל-Starter (7$/חודש) הוא הפתרון היחיד שבאמת מובטח.

## חיבור הדומיין soleluna.co.il

בעמוד השירות ב-Render: **Settings → Custom Domains → Add** `soleluna.co.il`,
ואצל רשם הדומיין הוסיפו את רשומת ה-CNAME/A ש-Render מציג. SSL אוטומטי.

## מעבר לתשלומים אמיתיים

כשמוכנים לחייב באמת (פירוט מלא ב-`README-תשלומים.md`):
1. ודאו שמפתחות Grow מולאו ועובד בהזמנת בדיקה (`GROW_ENV=sandbox`).
2. ב-Environment של Render שנו:
   - `GROW_ENV` → `production`
   - `ALLOW_DEMO_CHECKOUT` → `false`

## חשוב לדעת (תוכנית free)

- **שינה**: אחרי 15 דק' בלי גולשים השרת נרדם — הבקשה הראשונה לוקחת ~30 שניות. ה"מעורר" החינמי שתיארנו למעלה פותר את זה כל עוד הוא רץ. שדרוג ל-Starter (7$/חודש) מבטל את הבעיה לגמרי, בלי תלות בשירות חיצוני.
- **הזמנות**: בתוכנית free בסיס הנתונים מתאפס בכל deploy. לשמירה קבועה — שדרגו ל-Starter והסירו את ההערה מבלוק ה-`disk` ב-`render.yaml`. עד אז, מייל ההזמנות (Resend — ראו `.env.example`) מבטיח שלא תפספסו הזמנה.
