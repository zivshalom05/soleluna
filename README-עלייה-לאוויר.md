# sole&luna — עלייה לאוויר 🚀

האתר **מוכן לחלוטין**: קטלוג 20 פריטים, סל + קופונים, הרשמה/התחברות, checkout (דמו + Grow), ממשק אדמין, דפים משפטיים, SEO מלא, וסרטון קמפיין שמתנגן גם באייפון.

## פריסה ל-Render (5 דקות, תוכנית Starter — $7/חודש)

`render.yaml` מוגדר על **plan: starter** (לא free) — כדי שהאתר יהיה ער וזמין תמיד
ולא "יירדם" בין ביקורים, וכדי שדיסק קבוע ישמור את ההזמנות בין deploy ל-deploy.
זה דורש כרטיס אשראי מחובר לחשבון ה-Render שלכם.

1. היכנסו ל-[render.com](https://render.com) והתחברו עם GitHub.
2. **New → Blueprint** → בחרו את הריפו `zivshalom05/soleluna`.
   Render קורא את `render.yaml` ומקים את השירות לבד (יבקש אמצעי תשלום בשביל תוכנית Starter + הדיסק).
3. כשתתבקשו, מלאו את המשתנים:
   | משתנה | ערך |
   |---|---|
   | `ADMIN_PASS` | סיסמה חזקה לממשק האדמין (חובה) |
   | `GROW_USER_ID` / `GROW_PAGE_CODE` / `GROW_API_KEY` | מהדשבורד של Grow — או השאירו ריק בינתיים (יעבוד בדמו) |
4. **Apply** — תוך ~2 דקות האתר חי בכתובת `https://soleluna.onrender.com` (או דומה), ורץ לבד 24/7.

**כבר פרוס על תוכנית Free וכעת רוצים לשדרג?** אין צורך ליצור שירות חדש —
בעמוד השירות ב-Render: **Settings → Instance Type** → בחרו **Starter** ואשרו אמצעי תשלום.
הוספת הדיסק הקבוע (כבר מוגדר ב-`render.yaml`) תתבצע אוטומטית ב-deploy הבא לאחר השדרוג
(Render יזהה את שינוי ה-`render.yaml` ויציע להחיל אותו — לחצו **Sync**/**Apply**).

## חיבור הדומיין soleluna.co.il

בעמוד השירות ב-Render: **Settings → Custom Domains → Add** `soleluna.co.il`,
ואצל רשם הדומיין הוסיפו את רשומת ה-CNAME/A ש-Render מציג. SSL אוטומטי.

## מעבר לתשלומים אמיתיים

כשמוכנים לחייב באמת (פירוט מלא ב-`README-תשלומים.md`):
1. ודאו שמפתחות Grow מולאו ועובד בהזמנת בדיקה (`GROW_ENV=sandbox`).
2. ב-Environment של Render שנו:
   - `GROW_ENV` → `production`
   - `ALLOW_DEMO_CHECKOUT` → `false`

## חשוב לדעת (תוכנית Starter)

- **בלי שינה**: בניגוד לתוכנית Free, Starter לא "מרדים" את השרת בלי תנועה — האתר זמין תמיד, גם לביקור הראשון של היום.
- **הזמנות נשמרות לצמיתות**: הדיסק הקבוע שמוגדר ב-`render.yaml` שומר את קובץ ה-SQLite בין deploy ל-deploy, כך שההזמנות והמלאי לא מתאפסים יותר.
- כמובן, מייל ההזמנות (Resend — ראו `.env.example`) ממשיך לפעול כגיבוי נוסף לכל הזמנה.
